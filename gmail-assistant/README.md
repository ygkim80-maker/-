| 보안 | 신규 | 로그인/비밀번호 재설정 등 계정 보안 이벤트 — 우선 확인 필요 |

## 분류 규칙 (발신자/제목 기반)

- **보안**: `security@`, `noreply-accounts@google.com`의 로그인/계정 공유 알림, 비밀번호 재설정 메일
- **채용**: 채용공고/구인 문구가 명확한 LinkedIn·리멤버 메일 (단순 "~님을 만나보세요" 인맥 추천은 뉴스레터로 분류)
- **업무**: 등록된 행사(예: MS Frontier Transformation Week), 본인이 설정해둔 정기 리포트(예: 주간 입찰공고 리포트), 실사용 중인 개발 툴의 중요 변경 공지(예: GroqCloud 모델 단종)
- **뉴스레터**: 제품 업데이트/프로모션 광고, SNS 알림, Google 알리미 다이제스트, 시스템 자동 안내 메일

## 기능 범위

1. **자동 분류/라벨링** — 위 규칙에 따라 스레드 단위로 라벨 부여
2. **중요 메일 요약/브리핑** — 보안·업무·채용 라벨 대상만 브리핑에 포함, 뉴스레터는 건수만 요약
3. **답장 초안 자동 작성** — 실제 상대방의 개인 correspondence(발신자가 실제 사람이고 응답이 필요한 경우)에만 `create_draft`로 초안 생성. 뉴스레터/알림성 메일에는 적용하지 않음
4. **스팸/불필요 메일 정리** — 뉴스레터 라벨 부여까지는 자동 수행. 실제 휴지통 이동(`trash_thread`)·스팸 처리(`mark_thread_spam`)는 매일 자동 Routine에서는 실행하지 않고 "삭제 후보"로만 보고한다 (모바일에서 매번 승인 팝업이 뜨는 문제로 2026-08-20부터 정책 변경). 실제 삭제는 사용자가 요청할 때 이 세션에서 직접 수행
