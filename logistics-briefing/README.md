# 제니엘 물류브리핑 — 데일리 뉴스레터 루틴

제니엘시스템 전략사업팀용 물류/3PL/경쟁사 데일리 브리핑을 만드는 반자동 루틴 문서입니다.

## 동작 방식 (방법 A: 반자동)

1. 차장님이 대화로 "오늘 물류브리핑 만들어줘" 요청
2. 아래 6개 카테고리 키워드 기준으로 웹서치 실행
3. `sent-articles-log.md`를 확인해 이미 다룬 기사를 제외하고, 카테고리당 가장 중요한 1~2건만 선별
4. 이모지+텍스트 스타일(이미지/차트 없음)로 정리
5. Gmail 임시보관함(draft)에 생성 — 발송은 차장님이 직접
6. 이번에 반영한 기사를 `sent-articles-log.md`에 추가

## 표준 카테고리 (6개)

- 📦 물류/배송
- 🛒 이커머스/유통
- 💳 금융/결제
- 💊 헬스케어/실버
- 🤖 기술/AI
- 🏢 기업/정책

각 카테고리의 세부 키워드는 `keywords.json` 참고.

## 기사 추출 원칙

1. **최신성**: 발행일 기준 최근 7일 이내 기사만 사용
2. **중복 방지**: `sent-articles-log.md`에 이미 기록된 기사(제목/URL 기준)는 재사용하지 않음

## 배포 방식

- 현재: 받는 사람 전원을 To/Cc에 넣고 "전체 답장"으로 피드백 공유
- 팀 규모가 커지면 Google Groups 배포리스트(답장 시 그룹으로 회신 기본값) 전환 검토
